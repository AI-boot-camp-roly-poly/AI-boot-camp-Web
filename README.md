# CrackTwin Web

스카이베이 경포(S동·N동, 지상 20층) 구조물 균열 관리 디지털 트윈 웹 대시보드입니다.

- 홈: 위험 균열 목록, 기온·습도·바람
- 3D 시각화: 건물 모델 위 균열 지점, 바람 효과, 순찰 드론
- 균열 정보: 균열 사진·측정값·이력
- 드론 제어: UE5 Pixel Streaming 화면, 점검(관리자)

## 실행

빌드 없이 정적 파일로 동작합니다.

1. 설정 파일을 만듭니다. `config.js`는 내부망 주소가 들어가므로 깃에 올리지 않습니다.
   ```bash
   cp config.example.js config.js
   ```
2. `config.js`의 `<서버 PC IP>`, `<UE5 PC IP>`, `<터널 주소>`를 채웁니다.
3. 정적 서버로 엽니다.
   ```bash
   npx serve -l 3000
   ```

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 동작 전체 |
| `style.css` | 기본 스타일 |
| `theme.css` | 테마 (이 `<link>`를 빼면 기본 디자인으로 돌아감) |
| `config.example.js` | 서버 주소·건물 기준 설정 예시 |
| `assets/` | 로고 |

## 보안

- 관리자 토큰은 `sessionStorage`에만 저장하고, 비밀번호는 저장하지 않습니다.
- 서버 주소·비밀번호·토큰은 코드나 문서에 적지 않습니다.
